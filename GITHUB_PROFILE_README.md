## 🏆 Featured Projects

### 🏏 Cricket Analytics Pipeline
**Production-Ready GCP Data Pipeline**

[![Repository](https://img.shields.io/badge/View_Repository-222222?style=for-the-badge&logo=github)](https://github.com/jiyaan-data-engineering/cricket-analytics-pipeline)

> **Ingests ICC cricket batting rankings** → **Processes with Apache Beam** → **Stores in BigQuery** → **Visualizes in Looker Studio**

| Component | Technology | Status |
|-----------|-----------|--------|
| **Data Source** | RapidAPI (Cricbuzz) | ✅ Active |
| **Ingestion** | Cloud Run (Python) | ✅ Scheduled |
| **Processing** | Apache Beam / Dataflow | ✅ Streaming |
| **Storage** | BigQuery (3-Layer) | ✅ Optimized |
| **Orchestration** | Cloud Composer (Airflow) | ✅ DAGs |
| **Analytics** | Looker Studio | ✅ Dashboard |
| **Infrastructure** | Terraform | ✅ IaC |

**Key Metrics**:
- 📊 **300-500 records/day** ingested
- 💾 **$5-9/month** operational cost
- ⚡ **Sub-5 minute** end-to-end latency
- 🔄 **100% uptime** with auto-recovery
- 📈 **Scales to 1M+ records** seamlessly

**Architecture Highlights**:
- ✨ Medallion Architecture (Raw → Staging → Curated)
- 🌟 Star Schema with SCD Type 1 dimensions
- 🔐 Event-driven cloud functions
- 📝 Comprehensive documentation
- 🚀 Production-grade error handling
